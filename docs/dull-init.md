# dull init

Create a new dull.toml in the current directory.

## Usage

```console
dull init
```

## Description

Writes an empty [dull.toml](dull.toml.md) in the current directory.
It is the only command that runs without an existing `dull.toml` and
without a `.dull/` environment.

If `dull.toml` already exists, `dull init` does nothing.

## Options

None.
